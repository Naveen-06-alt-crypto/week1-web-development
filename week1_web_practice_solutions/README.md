# Week 1 – HTML, CSS and JavaScript Practice Solutions

This project contains beginner-friendly solutions for all five questions in the uploaded practice sheet.

## How to run
1. Extract the ZIP file.
2. Open the extracted `week1_web_practice_solutions` folder in VS Code.
3. Open any exercise folder.
4. Right-click its `index.html` and choose **Open with Live Server** (if the Live Server extension is installed), or open the HTML file in a browser.

## Exercises covered
1. Personal portfolio using HTML and CSS — `01-portfolio`
2. Responsive navigation bar — included in the portfolio and e-commerce pages
3. JavaScript form validation — `02-form-validation`
4. E-commerce landing page — `03-ecommerce-landing`
5. Flexbox and CSS Grid layouts — `04-flexbox-grid`

All examples use plain HTML, CSS and JavaScript. No framework or installation is required.
